# Contributing to Fixly

## Team workflow
1. Choose an assigned backlog task and create a branch from the latest main.
2. Make focused changes and commit regularly with descriptive messages.
3. Open a pull request describing the changes, linked task, and verification performed.
4. Request review from another team member.
5. Address feedback and obtain approval before merging into main.

## Contribution accountability
Each member uses their own GitHub account and commits their own work. Local Git commits must use a name and email associated with that member’s GitHub account.

Commit messages should explain the change, such as “Validate required job-posting fields.” Avoid vague messages and bulk uploads that hide individual contributions.

Pull requests and commit history provide evidence of each member’s work. Each member must be able to explain their contributions during the project defense.
